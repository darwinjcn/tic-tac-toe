# Tic-Tac-Toe en Python 🎮

Un juego clásico de Tic-Tac-Toe (Tres en Raya) por consola desarrollado en Python. La máquina juega con 'X' y el usuario juega con 'O'.

## 📌 Características
- Tablero dinámico renderizado en consola.
- La máquina inicia siempre en el centro (`X`).
- Validación de entradas del usuario para evitar posiciones ocupadas o inválidas.
- Detección automática de victorias, derrotas y empates.

## 🚀 Cómo ejecutar
1. Asegúrate de tener instalado Python 3.
2. Clona el repositorio:

bash
git clone https://github.com/darwinjcn/tic-tac-toe.git

3. Ejecuta el juego:

bash
python main.py
